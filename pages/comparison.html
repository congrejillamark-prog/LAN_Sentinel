Findings

Where the gap is

Device scanners

Fing, GlassWire and ntopng are strong in device visibility and unknown-device alerts, but offer little machine learning-based anomaly detection. Nmap discovers devices and ports only on demand.

Packet & wireless tools

Wireshark gives full packet visibility but only for manual analysis, and Kismet covers only the wireless layer.

IDS platforms

Snort, Suricata, Zeek and Security Onion offer wide threat coverage but depend on rule sets or scripts, need expertise and are heavier to deploy; none uses a learned model of normal behavior.

Darktrace

The only reviewed tool that uses machine learning to detect anomalies, but it is a commercial product.

LAN Sentinel

Combines device discovery, a machine learning baseline of normal behavior, detection of port scanning, ARP spoofing and traffic flooding, and a dashboard in one lightweight tool. It detects and alerts only; it does not block traffic or inspect encrypted payloads.

LAN Sentinel

An AI-based Network Intrusion Detection System for Local Area Networks using Traffic Anomaly Analysis.
